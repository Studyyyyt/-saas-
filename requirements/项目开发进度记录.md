### 阶段三：业务闭环 + AI 场景扩展（⏸ 未开始）

> **目标**：打通核心业务流，让 AI 能力覆盖更多场景。  
> **预计周期**：2-3 周

| 模块 | 状态 | 说明 |
|------|------|------|
| 预约→病历→处置→收费快捷流转 | ⏸ | 预约列表直接"开始就诊"自动带入患者信息；病历保存后自动创建处置记录；处置确认后一键生成收费单 |
| 耗材/义齿加工供应链联动 | ⏸ | 病历中开具的义齿加工单自动同步至技工订单；技工账单确认后自动扣减耗材库存 |
| 患者全生命周期管理 | ⏸ | PatientTimeline 整合咨询、预约、就诊、收费、随访、影像全量事件；患者标签智能规则 |
| AI 对话 UI 现代化 | ⏸ | 左侧会话历史列表 + 右侧对话区域 + Markdown 渲染 + 流式打字机效果 + 快捷问题推荐 |
| AI 病历摘要 | ⏸ | 根据病历内容自动生成结构化摘要（主诉、诊断、治疗计划） |
| AI 智能随访建议 | ⏸ | 根据患者病历和就诊历史，生成个性化随访话术和回访时间建议 |
| AI 经营洞察问答 | ⏸ | 自然语言查询经营数据（"上周哪个医生的业绩最高？"） |
| AI 患者风险评估 | ⏸ | 根据病历、影像、病史自动标记高风险患者并给出关注建议 |

**技术方案**：复用现有 `BusinessAnalysisChatService` 的会话管理和长期记忆机制；引入 Function Calling / Tool Use 能力，让 AI 能调用后端 API 查询实时数据。
