**开发优先级**: P0（已有页面，需补齐后端接口）

## 1. 功能描述

配置系统调用 AI 大模型时的供应商接口参数，包括：
- 供应商名称（OpenAI、DeepSeek、硅基流动等）
- API 基础地址和密钥
- 模型名称
- API 类型（Chat Completions / Responses）
- 推理力度（低/中/高）
- 最大输出 Token 数
- 启用状态

**当前状态**: 前端页面已完成，需要后端提供配置持久化和连接测试接口。

### 5.2 需要修改的地方

**1. `loadConfig()` 方法**:

```javascript
async loadConfig() {
  this.loading = true
  try {
    const res = await this.$request.get('/api/ai-config/model-provider')
    if (res.code === '200' && res.data) {
      const data = res.data
      this.form.id = data.id || null
      this.form.providerName = data.providerName || ''
      this.form.baseUrl = data.baseUrl || ''
      this.form.modelName = data.modelName || ''
      this.form.apiType = data.apiType || 'chat_completions'
      this.form.reasoningEffort = data.reasoningEffort || 'medium'
      this.form.maxOutputTokens = data.maxOutputTokens || 3000
      this.form.enabled = data.enabled !== false
      // apiKey 返回的是脱敏的，前端留空表示不修改
      this.form.apiKey = ''
    }
  } catch (e) {
    this.$message.error('加载配置失败')
  } finally {
    this.loading = false
  }
}
```

**2. `saveConfig()` 方法**:

```javascript
async saveConfig() {
  if (!this.form.providerName.trim() || !this.form.baseUrl.trim() || !this.form.modelName.trim()) {
    this.$message.warning('请填写必填项')
    return
  }
  this.saveLoading = true
  try {
    const payload = {
      id: this.form.id,
      providerName: this.form.providerName.trim(),
      baseUrl: this.form.baseUrl.trim(),
      modelName: this.form.modelName.trim(),
      apiType: this.form.apiType || 'chat_completions',
      reasoningEffort: this.form.reasoningEffort,
      maxOutputTokens: this.form.maxOutputTokens,
      enabled: this.form.enabled
    }
    if (this.form.apiKey.trim()) {
      payload.apiKey = this.form.apiKey.trim()
    }
    const res = await this.$request.post('/api/ai-config/model-provider', payload)
    if (res.code === '200') {
      this.$message.success('保存成功')
      if (res.data && res.data.id) {
        this.form.id = res.data.id
      }
      this.form.apiKey = ''
    } else {
      this.$message.error(res.msg || '保存失败')
    }
  } catch (e) {
    this.$message.error('保存失败')
  } finally {
    this.saveLoading = false
  }
}
```

## 6. 后端实现要点

### 6.1 Controller

```java
@RestController
@RequestMapping("/api/ai-config/model-provider")
public class ModelProviderController {

    @Autowired
    private ModelProviderService modelProviderService;

    @GetMapping
    public Result getConfig() {
        return Result.success(modelProviderService.getCurrentConfig());
    }

    @PostMapping
    public Result saveConfig(@RequestBody ModelProviderDTO dto) {
        ModelProviderVO vo = modelProviderService.saveConfig(dto);
        return Result.success(vo);
    }

    @PostMapping("/test")
    public Result testConnection(@RequestBody ModelProviderTestDTO dto) {
        String result = modelProviderService.testConnection(dto);
        return Result.success(result);
    }
}
```

### 6.2 Service 核心逻辑

```java
@Service
public class ModelProviderServiceImpl implements ModelProviderService {

    @Autowired
    private ModelProviderMapper mapper;
    @Autowired
    private AesEncryptor encryptor;  // AES 加密器

    @Override
    public ModelProviderVO getCurrentConfig() {
        ModelProvider entity = mapper.selectCurrent();
        if (entity == null) return null;
        ModelProviderVO vo = new ModelProviderVO();
        BeanUtils.copyProperties(entity, vo);
        // 密钥脱敏显示
        if (StringUtils.hasText(entity.getApiKey())) {
            String decrypted = encryptor.decrypt(entity.getApiKey());
            vo.setApiKey(maskKey(decrypted));
        }
        return vo;
    }

    @Override
    public ModelProviderVO saveConfig(ModelProviderDTO dto) {
        ModelProvider entity = mapper.selectById(dto.getId());
        if (entity == null) {
            entity = new ModelProvider();
        }
        BeanUtils.copyProperties(dto, entity);
        // 有值才更新密钥
        if (StringUtils.hasText(dto.getApiKey())) {
            entity.setApiKey(encryptor.encrypt(dto.getApiKey()));
        }
        if (entity.getId() == null) {
            mapper.insert(entity);
        } else {
            mapper.updateById(entity);
        }
        return getCurrentConfig();
    }

    @Override
    public String testConnection(ModelProviderTestDTO dto) {
        // 使用 RestTemplate 发送一个简单请求测试连接
        // 发送 "你好" 或空请求，验证 API 密钥和地址有效性
        long start = System.currentTimeMillis();
        // ... 调用模型 API 测试
        long latency = System.currentTimeMillis() - start;
        return String.format("连接成功，模型响应延迟 %dms", latency);
    }

    private String maskKey(String key) {
        if (key.length() <= 8) return "****";
        return key.substring(0, 4) + "****" + key.substring(key.length() - 4);
    }
}
```

### 6.3 连接测试实现细节

连接测试不保存配置，直接使用前端传入的参数临时调用：

```java
public String testConnection(ModelProviderTestDTO dto) {
    try {
        RestTemplate restTemplate = new RestTemplate();
        HttpHeaders headers = new HttpHeaders();
        headers.setContentType(MediaType.APPLICATION_JSON);
        if (StringUtils.hasText(dto.getApiKey())) {
            headers.setBearerAuth(dto.getApiKey());
        }

        Map<String, Object> body = new HashMap<>();
        body.put("model", dto.getModelName());
        body.put("messages", List.of(Map.of("role", "user", "content", "hi")));
        body.put("max_tokens", 5);

        HttpEntity<Map<String, Object>> request = new HttpEntity<>(body, headers);
        String url = dto.getBaseUrl().replaceAll("/$", "") + "/chat/completions";

        ResponseEntity<String> response = restTemplate.postForEntity(url, request, String.class);
        if (response.getStatusCode().is2xxSuccessful()) {
            return "连接成功";
        }
    } catch (Exception e) {
        return "连接失败：" + e.getMessage();
    }
    return "连接失败";
}
```
