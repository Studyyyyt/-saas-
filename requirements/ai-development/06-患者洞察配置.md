# 06. 患者 AI 洞察配置开发文档

**对应前端页面**: `PatientAIConfigView.vue`  
**对应后端模块**: `PatientInsightConfigController` + `PatientInsightService`  
**开发优先级**: P2（扩展功能）

---

## 1. 功能描述

配置患者列表页面和患者 360 详情页右侧的 AI 洞察面板。AI 根据患者的历史就诊数据、治疗记录、收费情况等多维度数据，生成结构化的洞察分析。

**洞察维度**:
- 治疗风险分析
- 消费潜力评估
- 复诊概率预测
- 流失风险预警
- 转介绍可能性评估

**输出形式**: 结构化 JSON，前端解析后渲染为洞察卡片。

### 5.2 关键逻辑

```javascript
methods: {
  async loadConfig() {
    const res = await this.$request.get('/api/ai-config/patient-insight')
    if (res.code === '200' && res.data) {
      this.config = { ...this.config, ...res.data }
    }
  },

  async saveConfig() {
    this.saveLoading = true
    const res = await this.$request.put('/api/ai-config/patient-insight', this.config)
    if (res.code === '200') {
      this.$message.success('配置已保存')
    }
    this.saveLoading = false
  },

  resetPrompt() {
    this.config.systemPrompt = defaultPrompt
    this.config.outputSchema = defaultSchema
  }
}
```

## 6. 后端实现要点

### 6.1 Controller

```java
@RestController
public class PatientInsightController {

    @Autowired
    private PatientInsightService patientInsightService;

    @GetMapping("/api/ai-config/patient-insight")
    public Result getConfig() {
        return Result.success(patientInsightService.getConfig());
    }

    @PutMapping("/api/ai-config/patient-insight")
    public Result saveConfig(@RequestBody PatientInsightConfigDTO dto) {
        patientInsightService.saveConfig(dto);
        return Result.success("保存成功");
    }

    @PostMapping("/api/ai/patient/{patientId}/insight")
    public Result generateInsight(@PathVariable Long patientId,
                                   @RequestBody PatientInsightRequestDTO dto) {
        PatientInsightVO insight = patientInsightService.generateInsight(patientId, dto);
        return Result.success(insight);
    }
}
```

### 6.2 Service 核心逻辑

```java
@Service
public class PatientInsightServiceImpl implements PatientInsightService {

    @Autowired
    private PatientMapper patientMapper;
    @Autowired
    private MedicalRecordMapper recordMapper;
    @Autowired
    private AppointmentMapper appointmentMapper;
    @Autowired
    private FinanceMapper financeMapper;
    @Autowired
    private ModelProviderService modelProviderService;

    @Override
    public PatientInsightVO generateInsight(Long patientId, PatientInsightRequestDTO dto) {
        // 1. 获取患者数据
        Patient patient = patientMapper.selectById(patientId);
        List<MedicalRecord> records = recordMapper.selectByPatientId(patientId);
        List<Appointment> appointments = appointmentMapper.selectByPatientId(patientId);
        List<Finance> finances = financeMapper.selectByPatientId(patientId);

        // 2. 构建数据上下文
        String dataContext = buildDataContext(patient, records, appointments, finances);

        // 3. 获取提示词配置
        AiPromptTemplate template = promptMapper.findByScene("patient_insight");
        String prompt = template.getSystemPrompt().replace("{patient_data}", dataContext);

        // 4. 调用大模型
        String aiResponse = callModel(prompt);

        // 5. 解析并返回
        PatientInsightVO insight = JSON.parseObject(aiResponse, PatientInsightVO.class);
        insight.setPatientId(patientId);
        insight.setGeneratedAt(LocalDateTime.now());
        return insight;
    }
}
```
