## 1. 项目概述

### 1.1 目标
将口腔 SaaS 管理系统中的 AI 功能统一纳入"系统设置 - AI 智能中心"进行管理，实现：
- AI 功能全局可控（总开关 + 各功能独立开关）
- 提示词模板前端可配置（非技术人员可修改）
- 知识库（病历模板）可维护
- 外部 AI Agent（n8n/Dify/Coze）可接入
- 各页面 AI 功能参数独立配置

### 1.2 范围

**包含功能**:
- AI 总览（全局控制 + 统计）
- 首页 AI 助手配置
- 模型供应商配置
- 外部 Agent 链接配置
- 病历 AI 扩写配置
- 患者 AI 洞察配置

**不包含**（后续迭代）:
- 随访 AI 生成配置
- 经营分析 AI 日报配置
- 智能分诊配置
- AI 对话历史记录管理

## 3. 技术栈与规范

### 3.1 前端
- **框架**: Vue 2.6.14 + Vue Router 3
- **UI 组件**: Element UI 2.15
- **样式**: 复用现有 Apple Design System（CSS 变量）
- **HTTP**: Axios（通过 `$request` 封装）

### 3.2 后端
- **框架**: Spring Boot 3.2.5
- **数据访问**: MyBatis + MySQL 8
- **迁移**: Flyway（新增脚本版本从 V33 开始）
- **响应格式**: `Result`（`code`/`msg`/`data`）

### 3.3 AI 调用规范
- **协议**: HTTP REST
- **格式**: OpenAI-compatible Chat Completions API
- **输出约束**: JSON Mode 或 JSON Schema
- **超时**: 默认 30 秒，可配置

## 5. 接口规范总览

### 5.1 AI 功能配置接口
```
GET    /api/ai-config/functions              获取所有AI功能配置
GET    /api/ai-config/functions/{key}         获取指定功能配置
PUT    /api/ai-config/functions/{key}         更新功能配置（开关、参数）
GET    /api/ai-config/overview                AI总览统计（今日调用数、token消耗等）
```

### 5.2 提示词模板接口
```
GET    /api/ai-config/prompts                 获取模板列表
GET    /api/ai-config/prompts/{id}            获取模板详情（含few-shots）
POST   /api/ai-config/prompts                 新增模板
PUT    /api/ai-config/prompts/{id}            更新模板
DELETE /api/ai-config/prompts/{id}            删除模板
POST   /api/ai-config/prompts/{id}/test       测试提示词效果
```

### 5.3 外部 Agent 接口
```
GET    /api/ai-agent/links                    获取Agent链接列表
POST   /api/ai-agent/links                    新增Agent链接
PUT    /api/ai-agent/links/{id}               更新Agent链接
DELETE /api/ai-agent/links/{id}               删除Agent链接
POST   /api/ai-agent/links/{id}/test          测试连接
POST   /api/ai-agent/invoke                   调用指定Agent（前端通过后端转发）
```

### 5.4 病历扩写配置接口
```
GET    /api/ai-config/medical-record          获取病历扩写完整配置
PUT    /api/ai-config/medical-record          保存病历扩写配置
GET    /api/ai-config/medical-record/fields   获取字段规则列表
PUT    /api/ai-config/medical-record/fields   批量更新字段规则
POST   /api/ai/medical-record/expand          执行扩写（供效果测试和正式调用）
```

### 5.5 患者洞察配置接口
```
GET    /api/ai-config/patient-insight         获取患者洞察配置
PUT    /api/ai-config/patient-insight         保存患者洞察配置
POST   /api/ai/patient/{patientId}/insight    生成指定患者洞察
```

## 6. 安全与可控性规范（强制）

### 6.1 提示词安全
1. **绝对禁止**: AI 不得输出确诊性断言（必须用"考虑/疑似/待排"）
2. **敏感词拦截**: 后端维护敏感词列表，AI 输出含敏感词时拒绝返回
3. **字段长度限制**: 每个字段必须配置 `max_length`，超长时截断或重试
4. **JSON Schema 约束**: 所有 AI 功能必须通过 JSON Schema 锁死输出格式

### 6.2 数据安全
1. **权限隔离**: AI 功能配置仅管理员可访问
2. **密钥加密**: `ai_agent_link.auth_secret` 必须 AES 加密存储
3. **调用审计**: 所有 AI 调用记录 `ai_operation_log`（输入、输出、采纳状态）

### 6.3 人机结合原则
1. AI 输出必须经医生**选择性采纳**，不能直接覆盖原内容
2. 前端必须提供"采纳/拒绝/修改"交互
3. 系统记录采纳率，用于优化提示词

## 9. 开发 checklist（全局）

### 后端通用
- [ ] 所有 Controller 添加 `@RestController` + `@RequestMapping`
- [ ] 所有接口返回 `Result` 统一结构
- [ ] 敏感字段（密钥）AES 加密存储
- [ ] Flyway 脚本命名规范：`V33__ai_system_config.sql`

### 前端通用
- [ ] 所有配置页面统一使用 `section-card` 卡片样式
- [ ] 保存按钮统一放在页面标题右侧
- [ ] 表单校验在提交前进行，错误时 `this.$message.warning()`
- [ ] 所有 AI 相关接口前缀 `/api/ai` 或 `/api/ai-config`

#### 前端常见问题记录
- **Element UI `el-dialog` 多弹窗遮罩层遮挡**：当同一页面存在多个 `el-dialog` 且同时打开时，`.v-modal` 遮罩层（z-index: 2000）可能覆盖掉后弹出的对话框内容（z-index: 2001），导致内容区显示为灰色、无法编辑。解决方案：给后弹出的对话框添加 `:modal="false"`，彻底禁用该对话框的遮罩层；或在需要遮罩时手动管理 `z-index`。
  - 发生页面：`MedicalRecordAIConfigView.vue` 中的「Prompt 预览」弹窗
  - 根因：Element UI 的 `v-modal` 与 `el-dialog__wrapper` 处于同一层级，`v-modal` 的 z-index 与对话框接近时可能产生覆盖

### 联调规范
- [ ] 每个页面开发完成后，在浏览器验证完整流程
- [ ] 验证错误场景（网络中断、AI 返回异常、校验失败）
- [ ] 验证权限控制（非管理员访问应被拦截）
