# 05. 病历 AI 扩写配置开发文档

**对应前端页面**: `MedicalRecordAIConfigView.vue`  
**对应后端模块**: `MedicalRecordAIConfigController` + `MedicalRecordAIService`  
**开发优先级**: P1（核心功能）

---

## 1. 功能描述

配置病历编辑页面中"AI 一键扩写"功能的完整行为参数。医生填写简要病历信息后，AI 根据配置好的提示词模板、字段规则和安全策略进行专业扩写。

**核心能力**:
- 字段级控制：哪些字段支持扩写、最大长度、必填校验
- 提示词模板：可编辑的系统提示词，支持变量注入和 Few-shot 示例
- 安全策略：敏感词拦截、禁用确诊断言、输出规则校验
- 效果测试：页面内实时测试，即时验证提示词效果

### 6.2 Service 核心逻辑（扩写流程）

```java
@Service
public class MedicalRecordAIServiceImpl implements MedicalRecordAIService {

    @Autowired
    private AiPromptTemplateMapper promptMapper;
    @Autowired
    private MedicalRecordAIFieldMapper fieldMapper;
    @Autowired
    private ModelProviderService modelProviderService;
    @Autowired
    private AiOutputValidator validator;

    @Override
    public Map<String, String> expand(MedicalRecordExpandDTO dto) {
        // 1. 获取配置
        AiPromptTemplate template = promptMapper.findByScene("medical_expand");
        List<MedicalRecordAIField> fields = fieldMapper.selectAllEnabled();

        // 2. 渲染提示词
        String systemPrompt = renderPrompt(template, dto.getFields());

        // 3. 调用大模型
        String aiResponse = callModel(systemPrompt, dto.getFields());

        // 4. 解析 JSON
        Map<String, String> result = JSON.parseObject(aiResponse, new TypeReference<>() {});

        // 5. 安全校验
        ValidationResult validation = validator.validate(result, fields);
        if (!validation.isValid()) {
            throw new AIValidationException(validation.getErrors());
        }

        // 6. 记录日志（非测试模式）
        if (!Boolean.TRUE.equals(dto.getTestMode())) {
            logOperation("medical_expand", dto.getFields(), result);
        }

        return result;
    }

    private String renderPrompt(AiPromptTemplate template, Map<String, String> fields) {
        String prompt = template.getSystemPrompt();
        prompt = prompt.replace("{input_fields}", formatFields(fields));
        // TODO: 知识库注入
        prompt = prompt.replace("{kb_content}", fetchKnowledgeBase(fields));
        return prompt;
    }

    private String callModel(String systemPrompt, Map<String, String> fields) {
        // 调用模型供应商配置中的 API
        ModelProviderVO provider = modelProviderService.getCurrentConfig();
        // 使用 RestTemplate 或 OpenAI SDK 发送请求
        // 强制 JSON Mode
        return aiClient.chatCompletion(provider, systemPrompt, JSON.toJSONString(fields));
    }
}
```

### 6.3 AI 输出校验器

```java
@Component
public class AiOutputValidator {

    public ValidationResult validate(Map<String, String> output, List<MedicalRecordAIField> fields) {
        List<String> errors = new ArrayList<>();

        for (MedicalRecordAIField field : fields) {
            String value = output.get(field.getFieldKey());

            // 必填校验
            if (Boolean.TRUE.equals(field.getIsRequired()) && !StringUtils.hasText(value)) {
                errors.add(field.getFieldName() + "不能为空");
            }

            // 长度校验
            if (field.getMaxLength() != null && value != null && value.length() > field.getMaxLength()) {
                errors.add(field.getFieldName() + "超过最大长度" + field.getMaxLength() + "字");
            }

            // 正则校验
            if (StringUtils.hasText(field.getValidationRule()) && value != null) {
                if (!value.matches(field.getValidationRule())) {
                    errors.add(field.getValidationHint());
                }
            }
        }

        // 诊断语气校验
        String diagnosis = output.get("diagnosis");
        if (StringUtils.hasText(diagnosis) && !diagnosis.matches(".*(考虑|疑似|待排|鉴别诊断).*")) {
            errors.add("诊断字段必须使用建议性语气");
        }

        // 敏感词校验
        String sensitiveWords = "确诊,绝对,保证,100%,肯定";
        for (String word : sensitiveWords.split(",")) {
            for (String value : output.values()) {
                if (value != null && value.contains(word.trim())) {
                    errors.add("输出包含敏感词：" + word.trim());
                }
            }
        }

        return errors.isEmpty() ? ValidationResult.success() : ValidationResult.fail(errors);
    }
}
```

## 附录：新增 AI 扩写字段的修改清单

> 当业务需要在病历 AI 扩写中增加新字段（如 `"allergyHistory"`）时，按以下清单修改。**`fieldKey` 是前后端唯一契约，三处必须完全一致，且确定后不可再改。**

### 1. 前端配置页（`MedicalRecordAIConfigView.vue`）

| 位置 | 修改内容 |
|------|---------|
| `fieldConfigs` 数组 | 追加新字段默认配置对象：`{ fieldKey: 'xxx', fieldName: '中文名', enabled: true, maxLength: 300, required: false, validationRule: '', validationHint: '' }` |
| `defaultFieldDescriptions` 对象 | 追加键值对：`xxx: '该字段的默认描述，用于恢复默认时重建 JSON 块'` |
