# 02. 首页助手配置开发文档

**对应前端页面**: `AIAgentConfigView.vue`  
**对应后端模块**: `AiAgentConfigController` + `AiAgentConfigService`  
**开发优先级**: P0（已有页面，需补齐后端接口）

---

## 1. 功能描述

配置首页右下角的 AI 助手悬浮窗中的角色卡片。每个角色包含：
- 名称、图标、主题色
- 快捷指令（点击后自动输入的常用问题）
- 系统提示词（定义该角色的专业能力边界）
- 启用的数据工具（决定该角色能查询哪些数据）

**当前状态**: 前端页面已完成，数据存在 localStorage 中，需要迁移到后端数据库。

## 5. 前端实现要点

### 5.1 当前代码分析

现有 `AIAgentConfigView.vue` 已实现完整的 UI 交互：
- Agent 卡片列表展示
- 新增/编辑弹窗（表单含名称、图标、主题色、快捷指令、提示词、工具授权）
- 删除确认
- localStorage 本地缓存作为降级

### 5.2 需要修改的地方

**1. `loadAgents()` 方法** — 优先从后端加载：

```javascript
async loadAgents() {
  this.loading = true
  try {
    const res = await this.$request.get('/api/ai-config/agents')
    if (res.code === '200' && Array.isArray(res.data)) {
      this.agents = res.data.map(item => this.backendToFrontend(item))
      // 同时更新 localStorage 作为离线缓存
      saveAgentsToStorage(this.agents)
    } else {
      this.agents = loadAgentsFromStorage() // 降级到本地
    }
  } catch (e) {
    this.agents = loadAgentsFromStorage() // 网络失败降级
  } finally {
    this.loading = false
  }
}
```

**2. `saveAgent()` 方法** — 区分新增和编辑调用不同接口：

```javascript
async saveAgent() {
  const payload = this.frontendToBackend(this.form)
  if (this.editingId) {
    // 编辑：调用 PUT
    const existing = this.agents.find(a => a.id === this.editingId)
    await this.$request.put(`/api/ai-config/agents/${existing.rawId}`, payload)
  } else {
    // 新增：调用 POST
    const res = await this.$request.post('/api/ai-config/agents', payload)
    if (res.code === '200') {
      this.form.rawId = res.data.id
    }
  }
}
```

**3. `removeAgent()` 方法** — 调用后端删除：

```javascript
async removeAgent(agent) {
  if (agent.rawId && !agent.isSystemDefault) {
    await this.$request.delete(`/api/ai-config/agents/${agent.rawId}`)
  }
  this.agents = this.agents.filter(a => a.id !== agent.id)
  saveAgentsToStorage(this.agents)
}
```

## 6. 后端实现要点

### 6.1 Controller

```java
@RestController
@RequestMapping("/api/ai-config/agents")
public class AiAgentConfigController {

    @Autowired
    private AiAgentConfigService agentConfigService;

    @GetMapping
    public Result list() {
        return Result.success(agentConfigService.listAll());
    }

    @PostMapping
    public Result save(@RequestBody AiAgentConfigDTO dto) {
        AiAgentConfig entity = agentConfigService.save(dto);
        return Result.success(entity);
    }

    @PutMapping("/{id}")
    public Result update(@PathVariable Long id, @RequestBody AiAgentConfigDTO dto) {
        agentConfigService.update(id, dto);
        return Result.success("更新成功");
    }

    @DeleteMapping("/{id}")
    public Result delete(@PathVariable Long id) {
        agentConfigService.delete(id);
        return Result.success("删除成功");
    }
}
```

### 6.2 Service 核心逻辑

```java
@Service
public class AiAgentConfigServiceImpl implements AiAgentConfigService {

    @Autowired
    private AiAgentConfigMapper mapper;

    @Override
    public List<AiAgentConfigVO> listAll() {
        List<AiAgentConfig> list = mapper.selectAll();
        return list.stream().map(this::toVO).collect(Collectors.toList());
    }

    @Override
    public AiAgentConfig save(AiAgentConfigDTO dto) {
        AiAgentConfig entity = new AiAgentConfig();
        BeanUtils.copyProperties(dto, entity);
        entity.setAgentKey(generateAgentKey());
        entity.setChips(JSON.toJSONString(dto.getChips()));
        entity.setEnabledTools(JSON.toJSONString(dto.getEnabledTools()));
        mapper.insert(entity);
        return entity;
    }

    @Override
    public void update(Long id, AiAgentConfigDTO dto) {
        AiAgentConfig entity = mapper.selectById(id);
        if (entity == null) throw new RuntimeException("配置不存在");
        // 系统默认不允许修改关键字段
        if (Boolean.TRUE.equals(entity.getIsSystemDefault())) {
            entity.setSystemPrompt(dto.getSystemPrompt());
            entity.setEnabledTools(JSON.toJSONString(dto.getEnabledTools()));
            entity.setChips(JSON.toJSONString(dto.getChips()));
        } else {
            BeanUtils.copyProperties(dto, entity);
            entity.setChips(JSON.toJSONString(dto.getChips()));
            entity.setEnabledTools(JSON.toJSONString(dto.getEnabledTools()));
        }
        mapper.updateById(entity);
    }

    @Override
    public void delete(Long id) {
        AiAgentConfig entity = mapper.selectById(id);
        if (entity != null && Boolean.TRUE.equals(entity.getIsSystemDefault())) {
            throw new RuntimeException("系统预设助手不可删除");
        }
        mapper.deleteById(id);
    }
}
```
