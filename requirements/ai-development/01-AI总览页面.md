# 01. AI 总览页面开发文档

**对应前端页面**: `AIOverviewView.vue`  
**对应后端模块**: `AiConfigController` + `AiConfigService`  
**开发优先级**: P0（基础框架）

---

## 1. 功能描述

AI 功能的全局控制面板，是用户进入"系统设置 - AI 智能中心"后的默认页面。提供：
1. AI 功能总开关（一键开启/关闭系统所有 AI 功能）
2. 调试模式开关
3. 今日 AI 调用统计（调用次数、Token 消耗、活跃功能数、错误率）
4. AI 功能列表（各功能的启用状态、今日调用量、快捷配置入口）

### 3.2 后端数据表

**`ai_function_config`** — AI 功能配置主表

```sql
CREATE TABLE ai_function_config (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    function_key VARCHAR(50) NOT NULL UNIQUE COMMENT '功能标识',
    function_name VARCHAR(100) NOT NULL COMMENT '功能名称',
    page_path VARCHAR(100) COMMENT '所属页面路径',
    is_enabled BOOLEAN DEFAULT TRUE COMMENT '是否启用',
    model_name VARCHAR(50) COMMENT '使用模型名称',
    prompt_template_id BIGINT COMMENT '关联提示词模板ID',
    extra_config JSON COMMENT '额外配置（各功能私有参数）',
    sort_order INT DEFAULT 0 COMMENT '排序',
    create_time DATETIME DEFAULT NOW(),
    update_time DATETIME DEFAULT NOW()
);
```

**`ai_operation_log`** — AI 操作日志表（用于统计）

```sql
CREATE TABLE ai_operation_log (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    function_key VARCHAR(50) COMMENT '功能标识',
    account_id BIGINT COMMENT '操作用户ID',
    input_snapshot JSON COMMENT '输入数据快照',
    ai_output TEXT COMMENT 'AI输出内容',
    is_adopted BOOLEAN COMMENT '医生是否采纳',
    token_used INT DEFAULT 0 COMMENT '消耗token数',
    error_msg TEXT COMMENT '错误信息',
    create_time DATETIME DEFAULT NOW()

```

### 5.1 组件结构

```
│   └── 4 个 stat-card

    └── el-table
```

### 5.2 关键逻辑

```javascript
methods: {
  // 加载统计数据和功能列表
  async loadData() {
    const [overviewRes, functionsRes] = await Promise.all([
      this.$request.get('/api/ai-config/overview'),
      this.$request.get('/api/ai-config/functions')
    ])
    if (overviewRes.code === '200') {
      this.stats = { ...this.stats, ...overviewRes.data }
      this.globalEnabled = overviewRes.data.globalEnabled
      this.debugMode = overviewRes.data.debugMode
    }
    if (functionsRes.code === '200') {
      this.aiFunctions = functionsRes.data
    }
  },

  // 全局开关变更
  async onGlobalSwitchChange(val) {
    await this.$request.put('/api/ai-config/global', {
      globalEnabled: val,
      debugMode: this.debugMode
    })
    this.$message.success(val ? 'AI 功能已全局开启' : 'AI 功能已全局关闭')
  },

  // 功能开关变更
  async onFunctionSwitchChange(row) {
    await this.$request.put(`/api/ai-config/functions/${row.key}`, {
      enabled: row.enabled
    })
    this.$message.success(`${row.name} 已${row.enabled ? '启用' : '禁用'}`)
  },

  // 跳转到配置页面
  goToConfig(row) {
    this.$router.push(row.configPath)
  }
}
```

### 5.3 样式规范
- 统计卡片使用渐变图标背景（4 种颜色区分）
- 功能列表操作列包含"配置"文字按钮 + 启用开关
- 禁用状态的功能行文字变灰

## 6. 后端实现要点

### 6.1 Controller

```java
@RestController
@RequestMapping("/api/ai-config")
public class AiConfigController {

    @Autowired
    private AiConfigService aiConfigService;

    @GetMapping("/overview")
    public Result getOverview() {
        return Result.success(aiConfigService.getOverview());
    }

    @GetMapping("/functions")
    public Result getFunctions() {
        return Result.success(aiConfigService.getFunctionList());
    }

    @PutMapping("/global")
    public Result updateGlobalConfig(@RequestBody GlobalConfigDTO dto) {
        aiConfigService.updateGlobalConfig(dto);
        return Result.success("保存成功");
    }

    @PutMapping("/functions/{key}")
    public Result updateFunctionStatus(@PathVariable String key,
                                       @RequestBody FunctionStatusDTO dto) {
        aiConfigService.updateFunctionStatus(key, dto.getEnabled());
        return Result.success("更新成功");
    }
}
```

### 6.2 Service 核心逻辑

```java
@Service
public class AiConfigService {

    @Autowired
    private AiFunctionConfigMapper functionMapper;
    @Autowired
    private AiOperationLogMapper logMapper;

    public OverviewVO getOverview() {
        LocalDateTime todayStart = LocalDate.now().atStartOfDay();
        // 今日调用次数
        int todayCalls = logMapper.countTodayCalls(todayStart);
        // 今日token消耗
        int todayTokens = logMapper.sumTodayTokens(todayStart);
        // 活跃功能数
        int activeFunctions = functionMapper.countActive();
        int totalFunctions = functionMapper.countTotal();
        // 错误率
        int errorCount = logMapper.countTodayErrors(todayStart);
        double errorRate = todayCalls > 0 ? (errorCount * 100.0 / todayCalls) : 0;

        return OverviewVO.builder()
            .todayCalls(todayCalls)
            .todayTokens(todayTokens)
            .todayTokensFormatted(formatTokens(todayTokens))
            .activeFunctions(activeFunctions)
            .totalFunctions(totalFunctions)
            .errorRate(Math.round(errorRate * 10) / 10.0)
            .globalEnabled(getGlobalEnabled())
            .debugMode(getDebugMode())
            .build();
    }
}
```
