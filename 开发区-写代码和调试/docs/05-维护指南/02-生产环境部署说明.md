# 生产环境部署说明

## 一、部署架构概述

```
┌─────────────────────────────────────────────────────────────────────────┐
│                              公网用户                                    │
└─────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                           云服务器（反向代理）                            │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐                  │
│  │  Nginx 80/443│  │  Nginx 80/443│  │   n8n 独立   │                  │
│  │  -> 前端页面  │  │  -> 后端 API  │  │   部署       │                  │
│  └──────┬───────┘  └──────┬───────┘  └──────────────┘                  │
└─────────┼────────────────┼──────────────────────────────────────────────┘
          │                │
          │   frp stcp 隧道 │
          │                │
┌─────────┼────────────────┼──────────────────────────────────────────────┐
│         │                │           本地电脑（Mac/PC）                   │
│         ▼                ▼                                              │
│  ┌──────────────┐  ┌──────────────┐                                    │
│  │  前端 7070   │  │  后端 8080   │                                    │
│  │  (Vue+Nginx) │  │ (Spring Boot)│                                    │
│  └──────┬───────┘  └──────┬───────┘                                    │
│         │                 │                                             │
│         └────────┬────────┘                                             │
│                  ▼                                                      │
│         ┌──────────────┐                                               │
│         │  MySQL 3306  │                                               │
│         └──────────────┘                                               │
│                                                                         │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  MCP Data Server (独立目录, 8000端口)                           │   │
│  │  通过 Claude Code CLI stdio 模式连接                            │   │
│  └─────────────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────────┘
```

**核心原则**：
- 系统服务（MySQL + 后端 + 前端）统一在 `clinic-saas-source/docker` 下通过 Docker Compose 管理
- MCP Data Server 完全独立，在 `mcp-data-server` 目录下单独启动
- 本地不运行 Nginx 反向代理（SSL/域名由云服务器 Nginx 处理）
- 本地仅运行 frp 客户端，通过 stcp 隧道将服务暴露到云服务器

---

## 二、前置条件

### 1. 本地电脑
- Docker + Docker Compose 已安装
- frp 客户端已下载（`frpc`）
- 至少 4GB 可用内存

### 2. 云服务器
- 已安装 frp 服务端（`frps`）
- 已安装 Nginx（处理反向代理和 SSL）
- 开放对应端口

## 三、环境变量配置

### 系统服务环境变量

在 `clinic-saas-source/docker/` 目录下创建 `.env` 文件：

```bash
# 数据库配置（建议生产环境使用强密码）
DB_USER=clinic_user
DB_PASSWORD=你的强密码
DB_ROOT_PASSWORD=你的root强密码

# 安全密码
SECURITY_PATIENT_ADMIN_SECONDARY_PASSWORD=246810

# JVM 参数
JAVA_OPTS=-XX:+UseContainerSupport -XX:MaxRAMPercentage=75.0 -Djava.security.egd=file:/dev/./urandom
```

### MCP Data Server 环境变量

在 `mcp-data-server/` 目录下确保 `.env` 文件已配置：

```bash
# 数据库连接（使用 Docker 网络或宿主机 IP）
DB_HOST=host.docker.internal
DB_PORT=3306
DB_USER=clinic_user
DB_PASSWORD=你的强密码
DB_NAME=clinic_system

# 后端 API 地址（Docker 网络内访问）
API_BASE_URL=http://host.docker.internal:8080

# 日志级别
LOG_LEVEL=INFO
```

## 五、MCP Data Server 独立启动

**重要：MCP Data Server 必须在系统服务启动后再启动，因为它需要连接数据库和后端 API。**

### 1. 启动 MCP Data Server

```bash
cd /Users/cherry/Downloads/口腔saas管理系统开发/mcp-data-server

# 首次构建
docker compose up -d --build

# 日常启动
docker compose up -d
```

### 2. 查看状态

```bash
docker compose ps
docker compose logs -f
```

### 3. Claude Code CLI 连接配置

在 `~/.claude.json` 中添加：

```json
{
  "mcpServers": {
    "clinic-data": {
      "command": "/Users/cherry/Downloads/口腔saas管理系统开发/mcp-data-server/run_stdio.sh",
      "type": "stdio"
    }
  }
}
```

**注意**：配置修改后需**完全重启 Claude Code**（包括关闭后台进程）才能生效。

## 六、frp 隧道配置

### 1. 云服务器（frps.ini）

```ini
[common]
bind_port = 7000
token = your_secure_token
```

启动：
```bash
./frps -c frps.ini
```

### 2. 本地电脑（frpc.ini）

```ini
[common]
server_addr = 你的云服务器IP
server_port = 7000
token = your_secure_token

# 前端页面隧道
[clinic-frontend]
type = stcp
sk = frontend_secret_key
local_ip = 127.0.0.1
local_port = 7070

# 后端 API 隧道
[clinic-backend]
type = stcp
sk = backend_secret_key
local_ip = 127.0.0.1
local_port = 8080
```

启动：
```bash
./frpc -c frpc.ini
```

### 3. 云服务器访问端（frpc.ini 或额外配置）

在云服务器上再运行一个 frpc 作为访问端：

```ini
[common]
server_addr = 127.0.0.1
server_port = 7000
token = your_secure_token

[clinic-frontend-visitor]
type = stcp
role = visitor
server_name = clinic-frontend
sk = frontend_secret_key
bind_addr = 127.0.0.1
bind_port = 7070

[clinic-backend-visitor]
type = stcp
role = visitor
server_name = clinic-backend
sk = backend_secret_key
bind_addr = 127.0.0.1
bind_port = 8080
```

## 七、云服务器 Nginx 反向代理配置

```nginx
# 前端页面
server {
    listen 80;
    server_name clinic.yourdomain.com;

    location / {
        proxy_pass http://127.0.0.1:7070;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}

# 后端 API
server {
    listen 80;
    server_name api.clinic.yourdomain.com;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

**建议**：使用 Certbot 配置 HTTPS。

## 八、启动顺序（重要）

```
第1步: 启动云服务器 frps
        ./frps -c frps.ini

第2步: 启动系统服务（MySQL + 后端 + 前端）
        cd clinic-saas-source/docker
        docker compose -f docker-compose.yml up -d

第3步: 等待后端健康检查通过（约 60 秒）
        docker compose logs -f backend
        # 看到 "Started SpringbootApplication" 即可

第4步: 启动 MCP Data Server
        cd mcp-data-server
        docker compose up -d

第5步: 启动本地 frpc
        ./frpc -c frpc.ini

第6步: 启动云服务器 frpc（访问端）
        ./frpc -c frpc_visitor.ini

第7步: 启动云服务器 Nginx
        sudo nginx -s reload
```

## 十、常见问题

### 1. 前端访问后端 API 返回 502

检查前端容器内的 `BACKEND_URL` 环境变量是否正确：
```bash
docker compose exec frontend printenv BACKEND_URL
# 应输出 http://backend:8080
```

### 2. MCP Data Server 连接数据库失败

因为 MCP Data Server 在独立 Docker 网络中，数据库在另一个网络。`.env` 中使用 `host.docker.internal`（Mac）或宿主机 IP（Linux）指向本地 MySQL。

### 3. 前端页面空白

检查前端是否正确构建：
```bash
docker compose logs frontend
# 应看到 "前端服务启动，后端代理地址: http://backend:8080"
```

### 4. frp 连接不上

- 检查云服务器防火墙是否放行 7000 端口
- 检查 `token` 是否一致
- 检查 `server_addr` 是否为公网 IP
