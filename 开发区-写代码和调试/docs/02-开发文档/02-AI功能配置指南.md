# AI功能配置指南

本文档说明如何在系统中配置AI功能。

## 首页助手配置

1. 进入「系统设置 → AI 智能中心 → AI 总览」。
2. 可以新增、编辑、删除AI助手。
3. 每个助手需要配置以下字段：

| 字段 | 说明 |
|------|------|
| 端点地址（URL） | 外部工作流端点的完整URL |
| 请求方法 | HTTP方法，如POST、GET |
| 认证类型 | Bearer、API Key、无 |
| 认证密钥 | 对应认证类型的密钥值 |
| 请求体模板（JSON） | 发送到外部端点的请求体模板 |
| 响应类型 | SSE（流式）或JSON（一次性） |
| 超时时间 | 请求超时时间（秒） |

4. 请求体模板支持的变量：

| 变量 | 说明 |
|------|------|
| `{{message}}` | 用户输入的消息内容 |
| `{{account_id}}` | 当前账号ID |
| `{{account_name}}` | 当前账号名称 |
| `{{session_id}}` | 当前会话ID |
| `{{clinic_id}}` | 当前诊所ID |

## 病历扩写配置（待重构）

> **当前状态**：病历扩写功能将单独通过独立工作流对接，不再依赖原内置配置页面。如需在病历页面使用 AI 扩写，请为 `medical-expand` 功能编码绑定新的 Agent 配置。

1. 进入「系统设置 → AI 智能中心 → AI 总览」。
2. 在「系统功能绑定」区域找到 `medical-expand` 功能编码。
3. 绑定到对应 Agent，配置其 Webhook 地址、认证和请求模板即可。

## AI总览

- **全局开关**：控制前端所有 AI 入口的显示/隐藏。
- **功能绑定**：每个系统功能编码（如 `home-assistant`、`medical-expand`）可独立绑定到一个 Agent，并控制其在目标页面和首页的显示。

## 废弃功能说明

以下功能已废弃，请勿使用：

- **模型供应商配置页面**：原用于配置API Key和模型参数，现已废弃，请使用「首页助手」配置外部端点。
- **患者洞察AI配置**：原用于配置患者洞察相关的AI参数，现已废弃。
