# 义齿加工模块使用说明

## 1. 配置加工厂与价格表

1. 进入“加工厂档案”页面，新增加工厂。
2. 进入加工厂详情，维护产品价格表。
3. 如需批量录入，按 `产品名称,规格,单价,单位` 一行一条录入即可。

## 2. 配置账单模板

1. 进入加工厂详情页，点击“配置账单模板”。
2. 上传一个该加工厂的示例 Excel。
3. 将 Excel 表头拖拽到系统字段槽位：
   - `产品名称`
   - `数量`
   - `金额`
   - 其余字段按实际情况映射
4. 保存模板。后续导入账单可直接复用。

## 3. 创建加工订单

1. 进入“加工订单”页面，新建订单。
2. 先选加工厂，再从价格表中选择产品，系统自动带出规格和单价。
3. 搜索并选择患者，可选关联治疗记录。
4. 录入数量、预计完成日期后保存，订单默认状态为“已下单”。

## 4. 导入月度账单

1. 进入“月度账单”页面，点击“导入账单”。
2. 选择加工厂、账单月份、对应模板。
3. 上传 Excel 后，前端按模板解析并展示预览。
4. 确认无误后提交，系统自动生成账单、账单条目并执行匹配。

## 5. 处理异常并完成对账

1. 打开账单详情页，查看四组结果：
   - 完全匹配
   - 数量/金额不符
   - 仅账单有
   - 仅系统有
2. 对异常记录逐条标记“已处理”或“已忽略”，并补充备注。
3. 所有异常处理完成后，点击“完成对账”。
4. 系统会自动：
   - 将匹配到的加工订单状态更新为“已对账”
   - 向 `finances` 写入一笔 `义齿加工` 支出
   - 将账单状态更新为“已完成对账”
