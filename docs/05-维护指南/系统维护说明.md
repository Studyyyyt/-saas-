# 系统维护说明

## Docker 开发环境

### 启动

```bash
cd shuao-clinic-saas-source/docker
docker compose -f docker-compose.dev.yml up -d
```

- 后端：`http://localhost:8080`
- 前端：`http://localhost:7070`

### 停止

```bash
cd shuao-clinic-saas-source/docker
docker compose -f docker-compose.dev.yml down
```

### 查看日志

```bash
docker compose -f docker-compose.dev.yml logs -f backend
docker compose -f docker-compose.dev.yml logs -f frontend
```

### 重新构建

仅在修改 Dockerfile、docker-compose 文件或新增系统级依赖时使用：

```bash
docker compose -f docker-compose.dev.yml up -d --build
```

## 后端热重载

项目已配置 `spring-boot-devtools`，修改 Java 代码后无需重启容器：

```bash
cd shuao-clinic-saas-source/docker
docker compose -f docker-compose.dev.yml exec backend mvn compile -q
```

约 0.3 秒后自动热重启。

## 前端构建

仅用于打包验证，不用于启动服务：

```bash
cd shuao-clinic-saas-source/saas-vue-src
npm install
npm run build
```

输出到 `dist/` 目录。

## 数据库迁移

使用 Flyway，迁移脚本位于 `saas-springboot-src/src/main/resources/db/migration/`。

- 版本从 V1 到 V32+
- 启动时自动执行
- 新增迁移脚本遵循 `V{版本号}__{描述}.sql` 命名规范

## 新增 AI Agent 配置步骤

1. 在数据库 `ai_agent_config` 表插入新记录，设置 `agent_key` 和外部端点 URL
2. 若需前端展示，在 `AIAgentConfigView.vue` 中添加对应配置表单
3. 在调用处使用对应的 `agentKey` 调用 `aiStreamClient.streamChat()`
4. 测试验证（参见 `docs/04-验证测试/验证清单.md`）

## 常见问题排查

| 问题 | 排查步骤 |
|------|---------|
| 后端无法启动 | 检查 `docker compose logs backend`，确认 MySQL 已启动且 Flyway 无冲突 |
| 前端热刷新失效 | 检查 `docker compose logs frontend`，确认 WebSocket 连接正常 |
| AI 请求无响应 | 确认外部端点 URL 可访问，检查后端日志中的代理请求记录 |
| 数据库迁移失败 | 检查 Flyway 版本冲突，手动执行 `repair` 或清理 `flyway_schema_history` |
| 登录失败 | 确认数据库中存在该用户，密码为明文比对（当前无加密） |
| 接口 404 | 确认 `SpaForwardController` 中已添加对应路由转发规则 |
