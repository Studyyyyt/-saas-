# 项目里程碑

## 项目基本信息

- **项目名称**：口腔门诊SaaS管理系统
- **技术栈**：Vue 2 + Spring Boot 3
- **主要入口**：管理后台（桌面端）、患者微信门户、员工微信H5工作台

- **AI代理层已上线**：`AiProxyService` + `AiProxyController`提供统一代理能力。
- **MCP服务已上线**：已提供9个Tools供外部工作流调用。
- **API文档接口已上线**：`/api/docs`接口提供系统API文档。
