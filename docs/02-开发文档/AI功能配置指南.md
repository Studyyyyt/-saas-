# AI功能配置指南

本文档说明如何在系统中配置AI功能。

## 首页助手配置

1. 进入「系统设置 → AI智能中心 → 首页助手」。
2. 可以新增、编辑、删除AI助手。
3. 每个助手需要配置以下字段：

| 字段 | 说明 |
|------|------|
| 端点地址（URL） | 外部工作流端点的完整URL |
| 请求方法 | HTTP方法，如POST、GET |
| 认证类型 | Bearer、API Key、无 |
| 认证密钥 | 对应认证类型的密钥值 |
| 请求体模板（JSON） | 发送到外部端点的请求体模板 |
| 响应类型 | SSE（流式）或JSON（一次性） |
| 超时时间 | 请求超时时间（秒） |

4. 请求体模板支持的变量：

| 变量 | 说明 |
|------|------|
| `{{user_message}}` | 用户输入的消息内容 |
| `{{account_id}}` | 当前账号ID |
| `{{account_name}}` | 当前账号名称 |
| `{{session_id}}` | 当前会话ID |
| `{{history}}` | 历史对话记录 |

## 病历扩写配置

1. 进入「系统设置 → AI智能中心 → 病历扩写」。
2. 配置外部扩写端点：
   - 端点地址（URL）
   - 认证类型与密钥
   - 请求模板
3. 保留字段配置：
   - 启用/禁用各字段
   - 设置最大长度等约束
4. 诊疗场景库管理：维护扩写可用的诊疗场景。
5. 请求模板支持的变量：

| 变量 | 说明 |
|------|------|
| `{{fields}}` | 当前病历字段内容 |
| `{{scene_id}}` | 选中的场景ID |
| `{{scene_name}}` | 选中的场景名称 |
| `{{operations}}` | 操作列表 |
| `{{account_id}}` | 当前账号ID |
| `{{account_name}}` | 当前账号名称 |
| `{{enabled_fields}}` | 已启用的字段列表 |

## AI总览

- **全局开关**：控制前端所有AI入口的显示/隐藏。
- **功能开关**：可独立控制各AI功能的启用状态（如首页助手、病历扩写等）。

## 废弃功能说明

以下功能已废弃，请勿使用：

- **模型供应商配置页面**：原用于配置API Key和模型参数，现已废弃，请使用「首页助手」配置外部端点。
- **患者洞察AI配置**：原用于配置患者洞察相关的AI参数，现已废弃。
