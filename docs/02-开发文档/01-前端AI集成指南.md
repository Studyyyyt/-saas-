# 前端 AI 集成指南

## 概述

前端 AI 功能已通过统一代理层接入外部工作流平台。系统本身不再维护 AI 逻辑，仅作为展示层和数据层，所有 AI 交互通过后端代理转发到外部端点。

## 统一代理接口

### 通用聊天接口

```javascript
import axios from 'axios'

// 统一 AI 代理调用（以首页助手为例）
const res = await axios.post('/api/ai/proxy/home-assistant', {
  message: '用户输入内容',
  account_id: localStorage.getItem('account_id'),
  account_name: localStorage.getItem('account_name'),
  session_id: 'xxx',
  clinic_id: 1
  // ... 其他业务字段
})
// res.data.data 即为 AI 返回内容
```

后端代理路径：`POST /api/ai/proxy/{agentKey}`

### 病历扩写接口

```javascript
// 病历 AI 扩写调用
const res = await axios.post('/api/ai/proxy/medical-expand', {
  message: currentRecordContent,
  account_id: localStorage.getItem('account_id'),
  account_name: localStorage.getItem('account_name')
})
```

后端代理路径：`POST /api/ai/proxy/medical-expand`

## 支持的模板变量

前端在调用代理接口时，可在请求体或模板配置中使用以下变量：

| 变量名 | 说明 |
|--------|------|
| `{{message}}` | 用户当前输入的消息内容 |
| `{{account_id}}` | 当前登录账号 ID |
| `{{account_name}}` | 当前登录账号名称 |
| `{{session_id}}` | 当前会话 ID |
| `{{clinic_id}}` | 当前诊所 ID |
| `{{fields}}` | 动态字段数据对象 |
| `{{scene_id}}` | 当前场景 ID |
| `{{scene_name}}` | 当前场景名称 |
| `{{operations}}` | 可用操作列表 |

## 接入新 Agent 步骤

1. 在「系统设置 → AI 智能中心 → AI 总览」中新增 Agent 配置，设置 `agentKey` 和外部端点 URL。
2. 在「系统功能绑定」区域将目标功能编码绑定到该 Agent。
3. 前端在需要调用的页面通过 `axios.post('/api/ai/proxy/{agentKey}', { message, account_id, ... })` 发起请求。
4. 根据 `responseType` 处理响应：`json` 直接取 `res.data.data`；`sse` 需使用 `EventSource` 处理流式数据。

## 注意事项

- 响应类型（`json` / `sse`）由 Agent 配置决定，前端需根据配置选择对应的请求处理方式
- 若外部端点未配置或返回异常，前端应展示友好的错误提示
- 请求体中的字段会按 `request_template` 进行后端模板变量替换，无需前端拼接模板
