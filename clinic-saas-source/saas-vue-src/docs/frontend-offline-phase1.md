# 纯前端离线一期说明

## 本期范围

- 在线成功登录一次后，同一浏览器可在断网刷新后继续进入系统。
- 离线可查看最近缓存：
  - 首页概览 / 医生首页
  - 患者列表
  - 预约看板
  - 患者360
  - 病历列表
- 离线可保存到待同步队列：
  - 患者新增/编辑
  - 预约新增/编辑
  - 病历新增/编辑
- 网络恢复后会自动补同步；页面初始化时也会尝试补同步。
- 页面顶部增加全局状态条：
  - 在线
  - 离线
  - 已回退缓存
  - 同步中
  - 同步失败

## 使用方式

1. 先在联网状态下登录一次。
2. 常用列表页、患者360页会把最近一次成功返回的数据缓存在浏览器 IndexedDB。
3. 断网后保存患者、预约、病历时，页面会提示“已离线保存，待同步”。
4. 恢复网络后，系统会自动回放待同步操作。
5. 若同步失败，顶部状态条会显示失败状态，可点击“重试同步”。
6. 若断网或请求超时后命中缓存，顶部状态条会明确显示“已回退缓存”，并标明缓存时间。

## IndexedDB 缓存淘汰策略

- 仅淘汰 `cacheEntries` 缓存数据，不会删除待同步队列与本地 ID 映射。
- 缓存默认保留最近 14 天，过期后自动清理。
- 同一类请求最多保留最近 8 份缓存快照。
- 整体最多保留 120 份缓存，超过后按最近访问时间淘汰较旧数据。

## 本期限制

- 只支持单浏览器、单机断网续用，不支持多设备离线协同。
- 删除、批量删除、Excel 导出、影像上传下载、财务库存保险报表未做离线化。
- 离线新增患者后的本地临时 ID 仅用于本机浏览器内串联预约/病历待同步关系。
- 同步冲突未做复杂人工合并 UI，当前以保留失败状态并允许重试为主。
