# 耗材采购与库存模块使用说明

## 1. 分类管理

1. 进入“耗材分类管理”页面。
2. 一级分类首次部署后会自动初始化：
   - 种植类
   - 正畸类
   - 修复类
   - 基础耗材
   - 其他
3. 支持新增一级分类或二级分类。
4. 一级分类删除为软删除；二级分类只有未被耗材使用时才允许删除。

## 2. 耗材档案

1. 进入“耗材档案”页面。
2. 选择分类、填写规格/品牌/单位、最低库存预警值和当前库存。
3. 低库存筛选会显示 `current_stock <= min_stock_alert` 的耗材。

## 3. 采购单录入

1. 进入“采购记录”页面，新建采购单。
2. 录入采购日期、供应商、付款方式。
3. 可先上传发票图片或 PDF。
4. 在采购明细里按分类筛选耗材，再搜索选择耗材。
5. 录入单价、数量，系统自动计算小计和总金额。
6. 提交后系统会自动：
   - 写入采购单主表和明细表
   - 增加对应耗材库存
   - 调用共享财务入口写入一笔“耗材采购”支出

## 4. 采购单编辑与作废

- 采购单仅允许创建当天编辑。
- 作废仅 admin 可执行。
- 作废后系统会：
  - 扣减对应耗材库存
  - 删除关联财务支出记录
  - 将采购单状态改为“已作废”

## 5. 统计

统计页提供：

- 最近 12 个月采购总额
- 按一级分类分组
- 前 10 大供应商
- 当前库存预警列表
